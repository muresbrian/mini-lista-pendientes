# Reglas de trabajo — mini lista de pendientes

Este proyecto lo trabajamos entre Brian, Antigravity y Kurt (otro agente que trabaja desde GitHub).

## Flujo con GitHub

- Nunca se suben cambios directo a `main`.
- Cada cambio va en una rama nueva con nombre descriptivo.
- Se abre un pull request a `main` explicando qué se cambió y cómo probarlo.
- Brian revisa y fusiona antes de seguir con más cambios.

## Roles

- **Antigravity**: edita, corre y prueba el código en la PC de Brian.
- **Kurt**: lee el repo en GitHub, revisa cambios y propone los suyos en pull requests.
- Lo que no está subido a GitHub, no lo ve el otro. GitHub es el punto de encuentro.

## La app

- Una sola página (`index.html`), sin build ni servidor: se abre directo en el navegador.
- Los pendientes se guardan en el navegador (`localStorage`).
- Mantener el código simple y en español.
