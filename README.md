# Mini lista de pendientes

Primer proyecto en conjunto con **Kurt** y **Antigravity**, hecho desde cero para probar cómo trabajamos los dos con GitHub como punto de encuentro.

## Qué hace

Una lista de pendientes simple en una sola página (`index.html`):

- Agregar pendientes
- Marcarlos como completados
- Eliminarlos
- Se guardan en el navegador (localStorage), así no se pierden al recargar

## Cómo probarla

Abre `index.html` en el navegador. No necesita instalación ni servidor.

## Cómo trabajamos aquí

- **Kurt** trabaja desde GitHub: lee el repo, propone cambios en ramas y pull requests.
- **Antigravity** trabaja en la PC: edita, corre y prueba el código, y sube los cambios a GitHub.
- Lo que no está subido a GitHub, no lo ve el otro. GitHub es el punto de encuentro.
